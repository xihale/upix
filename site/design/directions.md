# Upix 落地页方向

## 任务与约束

在 site2 从零创建新落地页。不读取或借鉴 ../site 的页面与代码。用户后续明确指定使用 ../site/public/assets/source.webp 与 restored.webp，素材是唯一例外。产品事实来自 ../README.md:1–20：图像超分辨率、Android、桌面与 CLI、局域网加密协作。

用户任务：直观看清画质变化，了解如何获取 Upix。
主动作：拖动图像对比；次动作：获取产品。
设计北极星：让一张图的细节变化，成为整个页面的主角。
设备：桌面与手机；手机需保留完整主图与触摸对比。
验收重点：文字极少、图像有辨识度、对比可操作、主要动作明确、窄屏不裁切关键内容。

Design Read：面向图像创作者的超分辨率工具落地页，以一幅插画的展览和直接对比为核心，采用原生 CSS 的低密度视觉语言。
DESIGN_VARIANCE 8：构图有辨识度。MOTION_INTENSITY 4：动作服务细节显现。VISUAL_DENSITY 2：画面多、文字少。

## 已观察的同类画面

- Upscayl：https://upscayl.org/，1440 × 900。证据 references/upscayl.png。
- Magnific：https://www.magnific.com/，1440 × 900。证据 references/magnific.png。https://magnific.ai 已重定向到该页面。

观察与取舍：

1. Upscayl 首屏上方为单行导航，动作明确；Upix 保留单行导航，减少链接数量。
2. Upscayl 居中大标题先于图像出现，首屏出现抽象发光背景；Upix 用可观看的真实图像先表达结果。
3. Upscayl 使用两级灰白字强调标题中的主词；Upix 不用长口号，保留极短标题。
4. Upscayl 的对比控件可键盘操作；Upix 保留拖动和键盘输入这一品类基线。
5. Magnific 用满版场景摄影承载创作情绪；Upix 借鉴图像的尺度关系，换为细节可辨的单张静态照片。
6. Magnific 主图上叠加标题、功能列表、口碑与动作，信息较多；Upix 只保留图像对比和一个主要获取入口。
7. Magnific 白色按钮在暗画面上明确可见；Upix 的控件需放在安全区并验证对比度。
8. 两家均为无衬线标题；Upix 用字宽和字重变化形成自己的身份，不靠混搭衬线强调词。

## 方向 A：一幅作品的展览（已选定）

北极星：像走近一幅作品，亲手把细节揭开。
引擎：摄影展的作品尺度与观看距离，来自图像增强产品的真实产出。
首屏骨架：通栏上下堆叠。顶部细导航约 8%，短标题与动作约 17%，宽幅对比图约 75%。
字体：自托管 Manrope 400/600 与 Noto Sans SC 400，展示 40–78px，界面 14–16px；标题不混搭字体，使用 WOFF2 分发并附字体许可证。
色彩：#F3F4F5 底色、#131619 主文字、#3151D4 单一动作色；#D8DEE7 描边、#E5EAFB 选中底。
主视觉：用户指定的一组插画，原图 640 × 427，处理后 2560 × 1708；按原文件复制，不使用模拟模糊滤镜。不推断素材的模型、作者或授权来源。
控件：小幅圆角 4px，实体按钮与简洁滑杆；无卡片、无装饰标签。
放弃：功能卡片、长说明、信任数字、发光背景。

## 方向 B：光学暗房

北极星：把观看变成一次安静的聚焦。
引擎：图像观察与局部放大的光学行为，不增加暗房道具。
首屏骨架：居中单一物件。顶部导航约 8%，中央摄影约 75%，底部短标题与动作约 17%。
字体：自托管 Space Grotesk，展示 48–64px / 400，界面 14–16px / 500。
色彩：#121416 底色、#F2F4F6 主文字、#A7C9AD 单一动作色；#363C39 描边、#24352A 选中底。
主视觉：一张精细植物或物体近摄，局部放大交互让细节成为主角。
控件：全直角，照片外置清晰的键盘与触摸操作入口。
放弃：满屏粒子、循环光晕、假仪表盘、技术术语列表。

## 方向 C：流动的画布

北极星：划过画面，就能看见图像从像素中显现。
引擎：数字图像的采样与清晰度变化，直接来自超分辨率任务。
首屏骨架：画面即界面。摄影铺满首屏约 90%，导航、极短标题和动作沿画面安全区排列。
字体：自托管 Archivo，展示 72–104px / 600，界面 16px / 500。
色彩：#ECEFF2 界面中性底、#121518 主文字、#C74632 单一动作色；#D1D5D9 描边、#F5E6E2 选中底。
主视觉：横跨整个视口的艺术摄影，拖动时揭开清晰区域；控件文字置于固定可读底面。
控件：统一圆角 8px，触摸可拖动，画面与滑杆协同。
放弃：传统长页、图片上的说明标签、夸张口号、多个同意图按钮。

## 差异检验与当前状态

A 为通栏展览，B 为独立物件，C 为满版直接体验；骨架、字体、色彩与主视觉组织方式互异。A 的摄影展构图区别于 Upscayl 的居中发光英雄区；C 用全屏可操作对比区别于 Magnific 的摄影背景加功能列表。

用户选择方向 A。只实现这一方向，没有制作未选方向的页面。主图拖动支持鼠标、触摸和键盘，放大为同一组图片同步缩放。图片加载失败时禁用对比、显示重试；重试保留当前分界位置与放大状态。

## 实现与动效

原生 HTML/CSS/JavaScript，Vite 8.3.4 开发服务，GSAP 3.15.0 动效。前端依赖的官方类型接口来自 https://raw.githubusercontent.com/greensock/GSAP/master/types/scroll-trigger.d.ts；Context7 工具未提供，官网文档遇到验证页，因此采用上游接口定义。

手感：滑入，像沿着展览墙走近画面。主操作即时跟手，按钮按下缩小；拖动中把手放大 4%、加 2px 钴蓝内描边，松开回落。放大/还原 650ms 同步改变原图与处理图，桌面与手机分别把眼睛、发饰作为放大中心；首次出场 600ms 内完成。

滚动分镜：首屏出场后无滚动驱动动效；下方标题和设备入口按阅读顺序轻微位移出场，始终保持可读。减少动态效果时所有内容静态到位。

文案减法：删除“细节，自有分量。”“让每一处细节，被看见。”；局部作品区块（含标题“靠近一点。”）已按用户要求整体删除；不放功能说明卡片、评价、数字背书与装饰眉标；外链文字不带 ↗ 箭头（用户要求），分界把手保留 ‹ › 作拖动示意。保留产品类别、操作提示、对比对象和获取方式。

获取入口：Android 指向公开构建指南，CLI 指向 GitHub 最新发布页。公开仓库没有桌面工作台说明，删除无效的桌面获取入口；不把构建指南伪装成应用安装包。

设备约束：桌面上下堆叠；手机单列并保留人像主体。所选银白展览方向固定浅色，不增加切换主题的操作。
